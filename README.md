# Neon Breakout — арканоид для PSP (ARK-4)

Неоновый арканоид в стиле Neon Arcade. Нативный homebrew на C, без внешних библиотек.

## Управление
- D-Pad или стик — платформа (стик: чем сильнее наклон, тем быстрее)
- X — запустить мяч; с лазером — стрелять (зажатый X стреляет очередью)
- START — пауза, SELECT в паузе — выйти в меню, HOME — выход из игры

## Игра
8 уровней, потом они идут по кругу, а мяч каждый уровень чуть быстрее.
Кирпичи: цветные (1 удар), серебряные (2 удара), стальные (не разбиваются).
Из разбитых кирпичей иногда падают бонусы:

| Бонус | Что делает |
|---|---|
| **E** | широкая платформа на 15 с |
| **M** | мультимяч: каждый мяч делится на три |
| **S** | медленный мяч на 10 с |
| **L** | лазер на 12 с |
| **C** | мяч прилипает к платформе на 15 с, X — отпустить |
| **+** | дополнительная жизнь (максимум 6) |

Рекорд и лучший уровень сохраняются в `breakout.sav` рядом с EBOOT.PBP.

## Файлы
- `breakout.c` / `breakout.h` — игра: логика и отрисовка, от PSP не зависит
- `main.c` — платформенный слой PSP: экран, кнопки, стик
- `input.h` — маска кнопок
- `test_host.c` — проверка на ПК: робот-игрок, проверки бонусов и состояний, кадры в `out/*.bmp`
- `ICON0.PNG`, `PIC1.PNG` — значок и фон для меню PSP (нарисованы самой игрой)

## Сборка
Через GitHub: загрузите в репозиторий все файлы и папку `.github/workflows/build.yml`.
Сначала запускается проверка на ПК, потом сборка; результат — артефакт `NeonBreakout` с EBOOT.PBP.

Через Docker:

    docker run --rm -v "$PWD":/src -w /src pspdev/pspdev make

## Проверка на ПК

    tcc -o out/test.exe test_host.c          (Windows, TCC из ..\tools)
    gcc -O1 -o out/test test_host.c -lm      (Linux)

## Установка
Положите EBOOT.PBP в `ms0:/PSP/GAME/NeonBreakout/` на карте памяти PSP.
